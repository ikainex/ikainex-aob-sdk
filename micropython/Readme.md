# MicroPython Support

MicroPython board support is planned but is not currently implemented in this
directory. There are no MicroPython drivers or examples yet.

The current MCP3204 ADC and MCP2003B LIN implementations are available as
Arduino libraries in [`../arduino-libs/`](../arduino-libs/), and as STM32 C
middleware in [`../mcu-sdk/middlewares/stm32/`](../mcu-sdk/middlewares/stm32/).
